Google Antigravity CLI (agy) Reference

Autonomous Execution & Auto-Approval Playbook

Complete guide for granting continuous approval ("all yes") to let the agent run tasks end-to-end without stopping for confirmation prompts.

⚡ The "Run Until Done" Golden Command Full Bypass
CLI Flag

To launch or resume an Antigravity CLI session with blanket auto-approval across all tools, terminal commands, and file edits: 

# Resume latest session in 100% autonomous auto-approval mode
agy -c --dangerously-skip-permissions

# Or launch a brand new autonomous session
agy --dangerously-skip-permissions
🚀

Method 1: Launch Flags

YOLO Mode

Bypasses the permission gate at CLI initialization. Ideal for daily workflows, long builds, batch installs, and automated scripts.

# New session
agy --dangerously-skip-permissions

# Non-interactive headless run
agy --dangerously-skip-permissions -p "Fix build errors"
Scope: Applies to all tool actions for the entire lifetime of the process.
⌨️

Method 2: Mid-Session Hotkeys

Interactive TUI

Toggle execution modes inside an active CLI chat without closing your current conversation or restarting.

# In the prompt box, press:
Shift + Tab   # Cycle modes: plan -> accept-edits -> auto

# Or type slash command:
/mode auto
Tip: On tool prompt dialogs, hit [a] to select "Always allow" for that session.
🎯

Method 3: /goal Slash Command

Agentic Loop

Directs the planner to continuously loop through code modifications, command execution, and verification tests until the objective is verified.

# In active chat prompt:
/goal Implement database connection pool and run test suite
Behavior: Forces the model to diagnose errors and retry autonomously instead of pausing.

01 Comparison of Permission Modes

Mode / Mechanism File Edits Shell Commands Subagent Creation When to Use
--dangerously-skip-permissions Auto-Approved Auto-Approved Auto-Approved Autonomous tasks, long scripts, CI/CD, or trusted local codebases.
--mode auto Auto-Approved Safe/Sandbox Auto Prompted Normal coding flow; allows file updates without asking for every save.
--mode accept-edits Auto-Approved Prompts Every Time Prompts Every Time High-security environments where shell commands require manual review.
--mode plan Read-Only Blocked Blocked Design analysis, code reviews, and initial planning without making changes.

02 Shell Profile Convenience Setup (Aliases)

To launch autonomous sessions quickly without typing the full flag every time, add persistent aliases or wrapper functions to your shell profile: 

# macOS / Linux (~/.bashrc or ~/.zshrc)
alias agy-yolo="agy --dangerously-skip-permissions"
alias agy-c="agy -c --dangerously-skip-permissions"

# Reload profile:
source ~/.zshrc  # or ~/.bashrc
# Windows PowerShell ($PROFILE)
function agy-yolo { agy --dangerously-skip-permissions $args }
function agy-c { agy -c --dangerously-skip-permissions $args }

# Reload profile:
. $PROFILE

03 Safety Boundaries & Best Practices

⚠️
Security Notice for --dangerously-skip-permissions:

This flag allows the agent to run terminal commands (such as rm, package installations, database migrations, or network requests) without asking for manual confirmation. Only execute this flag in workspaces with version control (Git) or isolated environments (containers/VMs) so you can easily review or revert changes if necessary.

💡
Persistent Context & Guardrails:

Pair autonomous execution with a repository-level instruction file (such as AGENTS.md or CLAUDE.md) to define architectural boundaries, forbidden commands, and testing requirements. When resuming work via agy -c --dangerously-skip-permissions, the agent automatically respects those codified rules while executing end-to-end.
