# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Created a `CHANGELOG.md` file.
- Added a `.gitignore` file to ignore `node_modules`, `.env`, and `deno.lock`.
- Added Progressive Web App (PWA) support (`manifest.json`, `sw.js`, `icon.svg`) to the Hydro (Drink Water Reminder) app.
- Implemented daily goal tracking and local storage persistence for the Hydro app.
- Added browser notifications to the Hydro app.
- **Material 3 Website Studio overhaul**: Upgraded the basic builder into a premium layout editor featuring clean modern typography (`Outfit` and `Plus Jakarta Sans`) and sharp **Material Symbols Outlined** iconography.
- **Dynamic M3 Theme Palette Engine**: Implemented custom dynamic HSL coloring formulas supporting chosen seed colors and designer curated presets (Indigo Cobalt, Forest Emerald, Sunset Crimson, Lavender Amethyst, Midnight Obsidian).
- **Multi-Device Responsive Canvas Switcher**: Added viewport controls to scale canvas smoothly across Desktop (100%), Tablet (768px), and Mobile (375px) modes, including dynamic frame shell aesthetics and a light/dark canvas grid toggle.
- **Expanded Component Suite**: Added comprehensive modules including high-fidelity **Hero Banners**, responsive **Features Grids** (2-4 columns), **Accordion / FAQs** (with live preview expansion handlers), and responsive brand **Footers**.
- **Visual Margins & Padding Spacer Sliders**: Integrated inline range controls in the properties panel to adjust outer margins and inner paddings on any canvas element.
- **Interactive Element Control Overlays**: Created hover actions for active components containing drag indicators, manual Move Up / Move Down DOM triggers, Clone / Duplicate deep-copy operations, and smooth deletion animations.
- **1-Click Preset Layout Templates**: Designed and pre-loaded premium structural templates: SaaS Startup Landing Page, Creative Dev Portfolio, and Link-in-Bio Social Hub.
- **Premium Standalone Code Exporter**: Engineered a tabbed modal rendering Combined static codes, HTML markup, or raw CSS rules, complete with copy-to-clipboard actions and direct standalone `.html` project file downloads.

### Changed
- Rebuilt the `online_excel` application from scratch to be a highly realistic Excel clone, featuring a Ribbon UI, multi-sheet support, cell formatting, and an advanced formula parser.
- Restructured the workspace by moving each application into its own dedicated folder.
- Renamed the main HTML files for each application to `index.html`.
- Updated `main.ts` to scan subdirectories and serve static files properly.
- Improved the homepage UI generated by `main.ts` to display a cleaner grid of applications.
- Refactored `drinkWater.html` (now `drink_water/index.html`) with a modern glassmorphism design and the 'Outfit' font.
- Updated `deno.json` to properly map `@std/path` via `jsr:` resolving IDE errors in `main.ts`.
- Refactored `/material3_website_builder/index.html` completely into a clean, fully-functioning, self-contained single-page studio application.
- Rebuilt the homepage serve grid generated in workspace hub logic.

### Fixed
- Fixed template literal syntax errors in `main.ts`.
- Resolved Deno strict mode dependency issues in `main.ts` by using a bare specifier.
- Reordered canvas drop placeholders dynamically preventing visual reordering flicker.
